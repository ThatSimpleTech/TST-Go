TST Go desktop extension
========================

This spoofs GPS for websites in Chrome, Edge, Brave, Arc, or Firefox
on Mac, Windows, and Linux.

It does NOT change native apps (Find My, system Maps, most games).
Android phones should install the APK instead.

Chrome / Edge / Brave / Arc
---------------------------
1. Unzip this folder.
2. Open chrome://extensions (edge://extensions).
3. Turn on Developer mode.
4. Load unpacked → select this folder (the one with manifest.json).
5. Open TST Go in a tab, move the pin. Other tabs follow it.
   Or use the extension popup search.

Firefox
-------
1. Unzip this folder.
2. Open about:debugging#/runtime/this-firefox
3. Load Temporary Add-on → pick manifest.json
   (Firefox temporary add-ons reset when Firefox quits unless you sign them.)
