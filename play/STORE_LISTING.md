## Full description

TST Go is a location simulator for Android.

Search a place, double-tap the map, or use the joystick to walk, cycle, or drive. Save favorite pins on this device. When you turn on Broadcast and pick TST Go as the mock location app in Developer options, other apps can follow that pin.

TST Go does not change your IP address. It does not require an account. Favorites stay on the phone.

How to broadcast GPS to other apps:
1. Settings → About phone → tap Build number seven times
2. Settings → Developer options → Select mock location app → TST Go
3. Open TST Go, turn Broadcast on, then jump to a place
4. Force-close Maps (or the other app) and reopen it

Desktop computers: use the companion browser extension in the GitHub project. Mac, Windows, and Linux cannot mock native system GPS the way Android can.

Privacy policy: https://github.com/ThatSimpleTech/TST-Go/blob/main/public/privacy.html
